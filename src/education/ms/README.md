# Graduate Course Notes

My graduate coursework connects three recurring themes: building dependable systems, understanding learning and computation, and creating interactive visual technology.

## Systems & Theory

| Course | Focus |
| --- | --- |
| [CIS 5050 · Software Systems](./5050/) | Processes, concurrency, RPC, replication, fault tolerance, and distributed services |
| [CIS 5110 · Theory of Computation](./5110/) | Automata, computability, reductions, and complexity classes |
| [CIS 5550 · Internet and Web Systems](./5550/) | Web servers, distributed storage, crawling, search, analytics, and scalability |

## AI & Perception

| Course | Focus |
| --- | --- |
| [CIS 5190 · Applied Machine Learning](./5190/) | Supervised, unsupervised, and reinforcement learning with applied evaluation |
| [CIS 5800 · Machine Perception](./5800/) | Projective geometry, calibration, stereo, structure from motion, and reconstruction |
