## A Useful Tool Note Should Include

- 它解决的具体问题，以及不适用的边界。
- 最小可运行示例和必要前置条件。
- 最常见的失败模式与恢复步骤。
- 替代方案及选择它的理由。
- 最后验证日期，尤其是容易随版本变化的操作。
