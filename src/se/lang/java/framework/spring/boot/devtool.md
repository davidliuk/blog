# Spring Boot Development Tools

开发期工具用于缩短代码变化到本地反馈的时间，例如自动重启、配置提示和调试端点。它们不应进入生产运行路径。

## Restart Mental Model

自动重启通常把稳定依赖与频繁变化的应用类放入不同 classloader。代码变化后只重建应用层，因此比完整 JVM 重启快，但也可能暴露 classloader、静态状态和资源清理问题。

## Safe Use

- 仅加入 development scope，不打包到生产制品。
- 自动重启不能替代测试；它只缩短手动验证循环。
- 修改数据库、消息或外部资源时仍需显式清理与回滚。
- 遇到 class cast、资源重复注册或旧状态残留时，先做完整重启验证。
- 远程调试和管理端点必须遵守认证、网络隔离和敏感信息边界。

本地开发配置应尽量接近生产 contract，同时避免复制真实凭证和用户数据。
