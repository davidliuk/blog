# Computer Science

`cs` 目录整理为两条主线：

- `core`：偏底层基础，关注操作系统、计算机网络这类长期有效的基础知识。
- `design`：偏工程设计，关注 OOD、设计模式、系统设计与常见场景题。

## 阅读建议

### 从基础到工程

1. `./core/`
2. `./design/`

适合想先补底层认知，再看工程设计取舍的读者。

### 从面试到专题

1. `./design/system/`
2. `./design/ood/`
3. `./design/pattern/`
4. `./core/`

适合先准备系统设计 / OOD 面试，再反补基础知识的读者。

## 内容地图

### Core

- `./core/network/`：应用层、传输层、网络层相关知识。
- `./core/os/`：进程、内存、文件系统、I/O、内核等主题。

### Design

- `./design/ood/`：面向对象设计方法与建模练习。
- `./design/pattern/`：设计模式与常见结构化套路。
- `./design/system/`：系统设计方法、模块设计、案例与专题问题。

## 维护原则

- 目录页负责导航、分层与阅读路径。
- 专题页负责解释一个完整主题。
- 案例页负责展示一个具体系统的设计取舍。

如果两个页面讨论的是同一主题的不同视角，优先交叉链接，而不是重复抄写同样的内容。
