# IP

IP 层负责主机到主机之间的寻址与转发，是网络层最核心的协议之一。

## 核心作用

- 给主机分配逻辑地址
- 让数据包可以跨网络传输
- 配合路由器完成转发

## 需要区分的两个地址

- IP 地址：标识主机在网络中的逻辑位置
- MAC 地址：标识网卡在局域网中的链路层地址

在跨网络传输过程中：

- 源 IP 和目标 IP 通常保持不变
- 源 MAC 和目标 MAC 会随着每一跳转发不断变化

## MTU

不同链路的最大传输单元 `MTU` 不同，例如：

- 以太网常见 MTU 为 1500 字节
- 其他链路可能更大或更小

当 IP 包大于底层链路的 MTU 时，就需要分片或在更高层避免过大的报文。
