# Cache

这里的 cache 主要从计算机体系结构与操作系统视角理解，不是业务系统里的 Redis / CDN。

## 为什么需要 Cache

CPU、内存、磁盘之间速度差距极大，如果所有数据都直接从慢层读取，系统整体性能会被拖垮。

Cache 的作用就是：

- 利用时间局部性
- 利用空间局部性
- 用更小但更快的存储换取整体吞吐提升

## 常见层次

- CPU Cache：L1 / L2 / L3
- Page Cache：操作系统对磁盘页的缓存
- Buffer Cache：对块设备访问的缓存

## 和系统设计里的缓存区别

- 这里强调的是硬件与操作系统层的访问路径优化
- 系统设计里的缓存更强调热点数据、QPS、失效与一致性
