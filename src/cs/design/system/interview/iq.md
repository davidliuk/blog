# Interview Questions

这页收纳开放式场景题，重点不是背答案，而是练习拆题方法。

## 建议答题框架

1. 先澄清需求与约束
2. 再给一个能工作的基础方案
3. 最后讨论扩展点、瓶颈与 tradeoff

## 场景题

1. 二维码问题，长短链匹配和存储怎么做
2. 一个外卖平台上有一个外卖单子，现在有多名骑手想接这一单，如何保证只有一个骑手可以接到？
3. 如何把一个文件快速下发到 100w 个服务器？
4. 给每个组分配不同的 IP 段，怎么设计一种结构使得快速得知某个 IP 属于哪个组？
5. 典型 Top K 系列的问题：10 亿个数找最大的 10 个。
6. 设计一个微信发红包的 API，怎么保证不会有人领到 0 元，并且金额精确到分？
7. 分布式多个机器生成 ID，如何保证不重复？
8. 扫码登录是如何实现的？
9. 分布式集群中如何保证线程安全？
10. 某网站 / App 首页每天会从 10000 个商家里推荐 50 个商家置顶，每个商家有一个权值，如何推荐？第二天怎么更新推荐结果？
11. 如何设计一个本地缓存？需要考虑哪些方面？
