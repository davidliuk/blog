# Search

搜索系统通常可以拆成“采集 -> 构建索引 -> 检索 -> 排序”四个环节。

## 核心链路

1. 数据采集
2. 文档清洗与分词
3. 索引构建
4. 检索召回
5. 排序与重排

## 关键模块

- Crawler / 数据采集
- Indexer / 建索引
- Query Service / 查询服务
- Ranking / 排序服务
- Suggestion / 联想与补全

## 设计时要考虑什么

- 倒排索引怎么组织
- 文档更新如何增量生效
- 热门查询如何缓存
- 搜索结果如何分页
- 是否支持拼写纠错、联想、过滤和高亮
