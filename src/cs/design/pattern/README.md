# Design Pattern

> [参考教程](https://refactoring.guru/design-patterns)

设计模式不是为了背诵，而是为了识别“变化点”与“稳定点”。

## Families

- `./creational/`：创建型
- `./structural/`：结构型
- `./behavioral/`：行为型

## 当前覆盖

### Creational

- Singleton
- Prototype
- Pool

### Structural

- Adapter

### Behavioral

- Observer
- State
- Strategy
- Template Method

当前行为型模式先保留总览页，后续可以再逐步补单独专题。
