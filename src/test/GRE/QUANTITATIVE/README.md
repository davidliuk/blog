# GRE Quantitative Reasoning

Quant 的难点通常不是高等数学，而是在有限时间内准确翻译条件、识别结构、控制计算并检查边界。

## Solve in Five Steps

1. **Translate**：把文字条件转换为变量、范围、图形或表格。
2. **Classify**：识别是求值、比较、计数、比例还是数据解释。
3. **Choose**：决定代数推导、试数、估算、画图或代入选项。
4. **Compute**：保留单位、符号和精度，避免过早小数化。
5. **Verify**：检查定义域、极端值、整数条件和题目真正所问。

## Quantitative Comparison

四个选项代表固定关系。不要把一次试数当成证明：

- 构造两个合法样例得到不同关系，可以证明“不确定”。
- 要证明 A 或 B 恒大，需要覆盖整个条件范围。
- 比较差 `A - B` 时检查符号；比较比值 `A / B` 时先确认分母与正负。
- 几何图形除非明确说明，通常不能按比例测量。

## Error Taxonomy

| Type | Example | Repair |
| --- | --- | --- |
| Concept | 忘记余数、概率或几何性质 | 回到最小知识单元 |
| Translation | 漏掉整数、正数、distinct 等条件 | 建立条件清单 |
| Strategy | 可以估算却进行长计算 | 复盘更短路径 |
| Execution | 符号、单位、抄数错误 | 增加中间检查点 |
| Timing | 在单题投入过多 | 设定跳题规则 |

当前 Quant 为两个 section，共 12 + 15 题；时间和结构以 [ETS GRE Test Structure](https://www.ets.org/gre/test-takers/general-test/prepare/test-structure.html) 为准。
