# GRE Verbal Reasoning

Verbal 的核心不是孤立词汇量，而是用句内和篇章逻辑约束词义、推断作者意图，并区分“文本支持”与“听起来合理”。

## Blank Workflow

1. 暂时遮住选项，判断句子希望表达的方向。
2. 标出 contrast、cause、support、qualification 等逻辑信号。
3. 用自己的简单词填空，确定词性、褒贬和强度。
4. 再看选项，检查所有空格能否共同让整句成立。
5. Sentence Equivalence 同时验证句意等价，而非只找近义词。

## Reading Workflow

1. 记录作者在做什么：提出、质疑、解释、比较还是限定。
2. 为每段写一个功能标签，不复述所有细节。
3. 题目要求推断时，选择“必须成立”的最小结论。
4. 对每个选项找文本证据；超出范围、强度过高和关系倒置优先排除。
5. 复盘时区分 passage error 与 option error。

## Error Taxonomy

- Vocabulary unknown
- Logic signal missed
- Sentence structure misread
- Passage role misidentified
- Unsupported inference
- Option comparison failure
- Time allocation

当前 Verbal 为两个 section，共 12 + 15 题；时间和结构以 [ETS GRE Test Structure](https://www.ets.org/gre/test-takers/general-test/prepare/test-structure.html) 为准。
