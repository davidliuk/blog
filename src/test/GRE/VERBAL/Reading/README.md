# GRE Reading Comprehension

阅读题先理解论证结构，再判断题目要求的证据强度。长文章和短文章的阅读量不同，但答案都必须受文本约束。

## Notes

- [Dual-Line Reading](./dual-line/)：同时跟踪内容线与论证线。
- [Formula Method](./formula/)：按题型整理证据和排除规则。

## Passage Skeleton

1. Topic：讨论对象是什么？
2. Tension：旧观点、问题或争议是什么？
3. Position：作者或他人的主张是什么？
4. Evidence：理由、例子和研究结果支持什么？
5. Qualification：结论在哪些条件下成立？
