# GRE Analytical Writing

当前 Analytical Writing 包含一个 30 分钟的 **Analyze an Issue** 任务。目标不是给出“正确观点”，而是清楚界定立场、建立推理链，并处理例外和反方观点。

## Argument Architecture

1. **Interpret**：题目中的关键概念、范围和绝对化措辞是什么？
2. **Position**：给出可论证、带条件的立场。
3. **Reason**：每个主体段只承担一个独立理由。
4. **Evidence**：用历史、科学、政策、组织或个人经验解释机制。
5. **Qualification**：说明结论的边界，回应最有力的反方。
6. **Revise**：优先修复任务偏离、逻辑断裂和影响理解的语言错误。

## A Practical Outline

- Introduction：重新界定问题，明确 thesis 与条件。
- Body 1：主要理由 + 机制 + 具体例子。
- Body 2：第二个独立理由 + 证据。
- Body 3：反方或例外 + 为什么总体立场仍成立。
- Conclusion：总结判断原则，不机械复制开头。

## Review Rubric

| Dimension | Ask |
| --- | --- |
| Position | 立场是否明确、持续一致，并真正回应题目？ |
| Development | 理由是否解释“为什么”，例子是否服务于推理？ |
| Organization | 每段功能是否清楚，过渡是否表达真实关系？ |
| Language | 句子是否清晰、准确，并有足够变化？ |
| Control | 是否在时间内完成并留出可执行的检查时间？ |

最新任务结构以 [ETS GRE Test Structure](https://www.ets.org/gre/test-takers/general-test/prepare/test-structure.html) 为准。
