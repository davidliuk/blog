# Test Preparation

考试准备不是无限收集模板，而是一个可测量的训练过程：先定位能力缺口，再做针对性训练，用限时模考暴露真实问题，最后把错题转化为下一轮计划。

## The Study Loop

<div class="knowledge-flow" aria-label="Test preparation loop">
  <div class="knowledge-flow__item">
    <span class="knowledge-flow__index">01</span>
    <strong>Diagnose</strong>
    <p>用一次完整基线测试区分知识缺口、语言缺口、方法问题和时间压力。</p>
  </div>
  <div class="knowledge-flow__item">
    <span class="knowledge-flow__index">02</span>
    <strong>Drill</strong>
    <p>把薄弱项拆成可重复的小技能，控制变量训练并记录准确率与耗时。</p>
  </div>
  <div class="knowledge-flow__item">
    <span class="knowledge-flow__index">03</span>
    <strong>Simulate</strong>
    <p>在正式时间和界面约束下组合技能，训练节奏、注意力和取舍。</p>
  </div>
  <div class="knowledge-flow__item">
    <span class="knowledge-flow__index">04</span>
    <strong>Review</strong>
    <p>为每个错误标注根因，提炼规则并安排间隔复习，而不是只记答案。</p>
  </div>
</div>

## Build a Weekly System

| 训练类型 | 目标 | 建议记录 |
| --- | --- | --- |
| Baseline | 确定当前水平与主要瓶颈 | 分项成绩、耗时、主观负荷 |
| Skill drill | 单独修复一个微技能 | 正确率、平均耗时、错误类型 |
| Mixed set | 训练识别题型与策略切换 | 决策错误、节奏中断点 |
| Full simulation | 验证体力、顺序和时间分配 | 分段表现、波动、临场失误 |
| Error review | 把失误变成规则与复习任务 | 根因、修正规则、下次复习日期 |

## Error Taxonomy

- **Knowledge**：单词、语法、数学概念或题型规则不知道。
- **Comprehension**：材料理解错误，遗漏否定、比较、指代或逻辑关系。
- **Decision**：知道知识点，但选择了错误的解题路径。
- **Execution**：计算、记录、发音、拼写或输入时出错。
- **Timing**：方法可行，但在考试时间内无法稳定完成。
- **Attention**：看漏条件、过早作答或被局部信息带偏。
