# Language Foundations

词汇和语法不是独立科目，而是阅读、听力、口语和写作共同调用的基础设施。

## Notes

- [Vocabulary](./vocabulary.md)：词义、搭配、词根和间隔复习。
- [Grammar](./grammar.md)：句子结构、修饰关系和准确表达。

## From Recognition to Use

1. **Recognition**：看到或听到时能快速识别。
2. **Discrimination**：能区分近义词、语气和搭配限制。
3. **Retrieval**：不看提示也能主动回忆。
4. **Application**：能在阅读推理或口头、书面表达中正确使用。
