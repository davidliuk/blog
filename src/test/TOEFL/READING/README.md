# TOEFL Reading

当前 Reading 包含 **Complete the Words、Read in Daily Life、Read an Academic Passage**。训练重点不应锁定某一代题型，而应稳定提升三层能力：词句解码、信息关系和篇章结构。

::: tip About older notes
本目录保留了旧版学术文章题型分类和训练记录。它们仍适合练习词汇、长句、定位、推断和总结，但题量、时间和计分表不再作为当前规则。
:::

## Three Layers

| Layer | Question | Practice |
| --- | --- | --- |
| Word & sentence | 主干是什么？修饰语指向哪里？连接词表达什么关系？ | 词汇、语法、长难句拆分 |
| Information | 题目要定位事实、目的、推断还是改写？ | evidence sentence、同义改写、排除 |
| Passage | 每段承担什么功能，段落怎样推进全文？ | 段落标签、结构图、摘要 |

## Reading Workflow

1. **Preview the task**：先明确当前任务需要补词、生活信息检索还是学术理解。
2. **Read for structure**：识别主语、谓语、指代和逻辑连接，不逐字翻译。
3. **Locate evidence**：答案必须能回到文本证据；推断也不能越过材料边界。
4. **Compare options**：优先排除范围错误、因果倒置、偷换概念和过度推断。
5. **Review the miss**：区分没读懂、没定位、没比较和时间分配问题。

## Error Log

每道错题记录五列即可：task、evidence、my choice、why wrong、next rule。不要抄整篇解析，只保留能改变下一次决策的信息。

最新题型和时间以 [ETS Test Content and Structure](https://www.ets.org/toefl/test-takers/ibt/about/content.html) 为准。
