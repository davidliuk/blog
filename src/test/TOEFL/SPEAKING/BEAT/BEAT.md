# BEAT Practice Loop

BEAT 训练的目标不是背诵整篇答案，而是把有限语料转化为考场可检索、可组合、能在时间内清晰输出的表达模块。

## One Practice Cycle

1. **Baseline**：严格计时录音，不看参考答案；
2. **Evidence**：转写录音，标记内容缺口、停顿、发音和语法问题；
3. **Adjust**：只修改最影响理解的两到三个问题；
4. **Transfer**：把相同语料应用到一道新题，验证是否真正掌握。

## Review Record

| Field | What to Record |
| --- | --- |
| Prompt | 题目与任务类型 |
| Structure | 观点、理由、例子或阅读—听力关系 |
| Timing | 开头、主体、结尾分别用了多少秒 |
| Delivery | 停顿、重音、语速和可懂度 |
| Language | 可复用表达与需要修正的错误 |
| Next drill | 下一次只训练哪一个瓶颈 |

每周复测同一题一次，比较首答而不是只比较反复练习后的最好答案。稳定、清晰、结构完整比偶尔出现的复杂词汇更有价值。
