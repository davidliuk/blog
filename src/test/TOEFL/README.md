# TOEFL iBT

TOEFL 的核心仍然是学术英语沟通：快速理解信息、识别结构、提取证据，并在时间限制内完成清晰的口头或书面表达。

::: warning Format updated in 2026
2026 年 1 月 21 日起，TOEFL iBT 更新了题型并采用 1–6 分制；过渡期成绩单同时提供可比的 0–120 总分估计。本站早期 TPO、Task 1–4 和综合写作笔记仍可用于训练语言、听记和表达，但不能直接当作当前考试结构。
:::

## Current Test Map

| Section | Current task families | Approx. base time | Train this capability |
| --- | --- | ---: | --- |
| [Reading](./READING/) | Complete the Words; Daily Life; Academic Passage | 30 min | 词句理解、信息定位、篇章结构 |
| [Listening](./LISTENING/) | Response; Conversation; Announcement; Academic Talk | 29 min | 声音解码、逻辑跟踪、有效笔记 |
| [Writing](./WRITING/) | Build a Sentence; Email; Academic Discussion | 23 min | 语法控制、受众意识、论点展开 |
| [Speaking](./SPEAKING/) | Listen and Repeat; Interview | 8 min | 听说转换、流利度、即时组织 |

Reading 和 Listening 采用自适应设计，实际题量和时间可能变化。表格只用于建立训练地图，考试前应核对 [ETS Test Content and Structure](https://www.ets.org/toefl/test-takers/ibt/about/content.html)。

## A Capability-First Path

1. [Vocabulary & Grammar](../basics/)：把词汇从“认识”训练到能在声音、句子和输出中快速调用。
2. [Reading](./READING/)：先做句子主干，再做段落功能和全文结构。
3. [Listening](./LISTENING/)：从声音辨识进入逻辑关系，笔记只保留能帮助答题的信息。
4. [Speaking](./SPEAKING/)：用录音建立即时反馈，优先修复清晰度和稳定性。
5. [Writing](./WRITING/)：先保证任务完成与逻辑，再提高句法和词汇质量。
6. 每周至少一次 mixed practice；临近考试再增加完整限时模拟。

## Review One Practice Set

每套练习至少留下四类结果：

- **Answer evidence**：正确答案由材料中的哪一处信息支持？
- **Failure cause**：是不认识、没听见、理解错、方法错，还是来不及？
- **Reusable rule**：下次遇到相似信号，应该做什么？
- **Next drill**：需要重复训练的最小技能是什么？

## Scores and Reporting

当前成绩使用 1–6 分制，各 section 以 0.5 为增量，总分是四项平均后按规则取整。ETS 说明官方成绩通常在考试后 3 天进入账户；成绩有效期为两年。执行送分前，请核对 [ETS score guidance](https://www.ets.org/toefl/test-takers/ibt/scores/understand-scores.html) 和每个项目自己的要求。

## Legacy Notes

旧版材料不是废弃内容，而是一个技能练习库：

- 旧阅读题可继续训练长句、定位、推断和结构。
- 旧听力材料可继续训练讲座逻辑、对话意图和笔记。
- 旧口语题可继续训练限时组织、复述和录音复盘。
- 旧写作题可继续训练证据组织、段落展开和语言准确性。
