# TOEFL Listening

当前 Listening 覆盖 **Listen and Choose a Response、Conversation、Announcement、Academic Talk**。真正可迁移的能力是把连续声音转化为结构化含义，而不是记录每个单词。

::: tip About older notes
本目录中的旧版对话、讲座、精听和笔记材料仍有训练价值；旧题量、加试和换算表不再作为当前考试说明。
:::

## Deliberate Practice

1. 首遍按正式条件作答，不暂停。
2. 标记丢失发生在声音、词义、句法、逻辑还是注意力。
3. 对关键片段做短循环：听 → 复述 → 对照文本 → 再听。
4. 用一句话总结每段功能，再恢复完整内容结构。
5. 24–72 小时后重新裸听，验证问题是否真正修复。

## Note-Taking Rule

如果一个符号不能帮助回答“谁、为什么、发生了什么变化、证据是什么”，就不值得写。笔记的目标是减少工作记忆负担，而不是制造第二份原文。

最新题型和时间以 [ETS Test Content and Structure](https://www.ets.org/toefl/test-takers/ibt/about/content.html) 为准。
