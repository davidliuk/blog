# Advanced Data Structures

这些结构通常不是题目的“主角”，而是为了支持特定操作复杂度而出现的工具。

## Topics

- [Stack](./stack/)：单调栈、表达式和受限访问顺序。
- [Queue](./queue/)：队列、双端队列、单调队列与 Top-K。
- [Trie](./trie.md)：按前缀组织字符串或离散键。
- [B-Tree](./b-tree.md)：面向块存储和数据库索引的多路平衡树。
- [Stream](./stream.md)：数据流中的在线统计和有限内存处理。

先明确需要的查询与更新操作，再选择结构；复杂结构应当用真实复杂度收益来证明必要性。
