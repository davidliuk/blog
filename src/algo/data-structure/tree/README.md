# Tree

树把层级关系编码成递归结构。大多数树题可以从“当前节点需要从父节点得到什么、又需要向父节点返回什么”开始建模。

## Reading Checklist

- 前序、后序还是层序？“做事”的时机在哪里？
- 函数返回单个值、多个状态，还是直接修改外部结果？
- 空节点、叶节点和退化链是否都满足函数语义？
