# List and Sequence

这一组内容主要用来区分几个最容易混在一起的概念: `subarray`、`substring`、`subsequence`，以及不同公司高频题里常出现的线性题套路。

## In This Folder

- `subarray.md`: 连续数组问题
- `subsequence.md`: 非连续序列问题
- `nearest-sum.md`: 子序列和最接近目标值，典型引到折半搜索或背包
- `google.md`, `google3.md`: 公司高频线性题记录

## Quick Rule

- 连续：优先想双指针、滑动窗口、前缀和
- 非连续：优先想 DFS、DP、LIS / LCS 这类序列建模
