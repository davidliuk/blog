# Dynamic Programming Track

动态规划把递归树中重复出现的子问题合并成状态。真正困难的是状态定义和转移顺序，而不是写出二维数组。

## State Design

写转移前先完整说出：`dp[state]` 表示什么、从哪些更小状态得到、初始化是什么、答案在哪里。
