# Two Pointers Track

双指针通过维护两个位置之间的关系，把部分二重枚举降为一次扫描。先区分指针是**相向移动**还是**同向移动**，再明确窗口或区间的不变量。

## Checklist

- 两个指针各自代表什么边界？
- 每次移动后，什么条件必须仍然成立？
- 指针是否只单调移动，从而保证线性复杂度？
