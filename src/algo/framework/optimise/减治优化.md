# 减治

减治的核心不是“每次减一点”，而是**你能稳定排除一整块不可能成为答案的状态**。

## 典型信号

- 有序数组或广义单调结构
- 二值性 / 两段性
- 双指针能避免回头
- 排序后可以持续删除无效状态
