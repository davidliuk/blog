# 动态规划

在 `framework` 里，动态规划只保留判断标准，不再重复主树中的状态分类、模板和题型。

## 先问自己

1. 有没有重复计算？
2. 状态依赖是否有方向性、能形成 DAG？
3. 目标是不是最优值、方案数或可行性？

如果这三点大体成立，就应该直接去主树里的 DP 体系展开。
