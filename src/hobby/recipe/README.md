## Preparation Patterns

- **去腥**：根据食材选择焯水，或用清水、盐和少量淀粉处理；料酒、姜、葱用于补充香气，不替代食材的新鲜度。
- **控水**：煎、烤前擦干表面，能减少水汽并改善上色。
- **分阶段调味**：基础盐味在烹饪前后分配，易焦的酱料和糖放在后段。
- **温度优先**：时间只是参考；厚度、初始温度和设备功率都会改变结果。
- **记录迭代**：记下重量、温度、时间和结果，下次只改一个变量。

食品安全优先于口感实验；肉类和剩菜应按可靠的中心温度与储存规范处理。
