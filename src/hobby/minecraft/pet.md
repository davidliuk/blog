# Minecraft Pets

Small reference for keeping tamed mobs safe and useful.

- Name important pets so they are easy to identify.
- Keep sitting pets away from portals, lava, cactus, campfires, and crowded redstone machinery.
- Use leads or enclosed paths when moving animals through unfamiliar terrain.
- Record the base coordinates before long trips; Nether travel changes the coordinate scale.
- Back up the world before version upgrades or behavior-pack changes.

Different editions and releases can change taming, teleportation, and despawn behavior, so confirm version-specific mechanics in the [Minecraft Wiki](https://minecraft.wiki/).
